# Archivio di progettazione

Materiale storico da cui è nata la pagina Agorà Orbite (`public/orbite/`).
Tenuto nel repository come riferimento — **non fa parte del sito**: questa
cartella sta fuori da `public/`, quindi Vite non la pubblica.

Prima stava dentro `public/orbite/` (`project/`, `chats/`, `strumenti/`) e
finiva scaricabile da chiunque conoscesse l'indirizzo — verificato,
`/orbite/chats/chat1.md` rispondeva `200` in produzione. Spostata qui per
questo.

```
orbite-project/    export del tool di design (bozze, upload, prototipo .dc.html)
orbite-chats/      trascrizioni della conversazione di progettazione
orbite-strumenti/  script "usa e getta" per rigenerare le versioni dei loghi
index.txt.css      bozza abbandonata, non referenziata da nulla
```

Dettagli su ciascuno in `public/orbite/README.md`, sezione "Bundle originale".
